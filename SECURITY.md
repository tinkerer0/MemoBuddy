# Security policy

## Supported versions

Security fixes are provided for the latest published MemoPet release.

## Reporting a vulnerability

Please do not open a public issue for a vulnerability or include private memo content in any report. Use [Report a vulnerability](https://github.com/tinkerer0/MemoPet/security/advisories/new) to send a private report.

Include the affected MemoPet version, macOS version, reproduction steps, and impact. Replace note text, file paths, usernames, and custom images with sanitized examples.

MemoPet's update checker only reads public GitHub Release metadata. It does not download or execute updates; users choose whether to open the validated GitHub release page.

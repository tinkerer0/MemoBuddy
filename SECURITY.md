# Security policy

## Supported versions

Security fixes are provided for the latest published MemoBuddy release.

## Reporting a vulnerability

Please do not open a public issue for a vulnerability or include private memo content in any report. Use [Report a vulnerability](https://github.com/tinkerer0/MemoBuddy/security/advisories/new) to send a private report.

Include the affected MemoBuddy version, operating system (macOS or Windows) and version, reproduction steps, and impact. Replace note text, file paths, usernames, and custom images with sanitized examples.

MemoBuddy 1.0 has no update checker and makes no network requests of its own; its menu can only ask your browser to open the privacy policy and license pages. The older Swift MemoPet (v0.4.x) update checker only reads public GitHub Release metadata; it does not download or execute updates.

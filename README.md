# MemoBuddy

(Formerly MemoPet.)

A tiny pet that stays on your screen and keeps your notes. Click it to write or draw; click anywhere else and it's saved.

- **Get it**: [Microsoft Store](https://apps.microsoft.com/detail/9mv1clqjv6cx) (Windows). A Mac App Store version is coming.
- **Privacy policy**: [docs/PRIVACY.md](docs/PRIVACY.md). No account, ads or tracking; notes stay on your computer.
- **Support and feedback**: [Issues](https://github.com/tinkerer0/MemoBuddy/issues).
- **Open-source components**: [THIRD_PARTY_LICENSES.md](THIRD_PARTY_LICENSES.md).
- **Security reports**: [SECURITY.md](SECURITY.md).

## Source code

The source code is no longer published in this repository. Earlier versions in its history, including the original Swift/AppKit MemoPet releases, remain available under the [MIT License](LICENSE).
